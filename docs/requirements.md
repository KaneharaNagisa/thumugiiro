# THUMUGIIRO 要件定義書

**文書種別**：事業用Webサイト・業務管理システム 要件定義書
**対象**：エンドユーザー画面（公開サイト・会員マイページ）／ 管理画面
**バージョン**：2.0（AIチャットウィジェット・会話履歴管理対応）

---

## 1. システム全体方針・技術スタック

- **フレームワーク**：PHP 8.3 / Laravel 11
- **環境**：Docker（PHP-FPM / Nginx / MySQL 8.0 / Redis等）
- **分離原則**：公開側（エンドユーザー・会員）と管理側は、認証・権限・ルーティング・デザインシステムを完全に分離する。
- **会計連携**：青色申告は自作システムで完結させず、仕訳CSV出力により会計ソフト（マネーフォワード クラウド確定申告等）へ取り込む。

## 2. エンドユーザー画面の要件

### 2.1 公開ページ・機能一覧

| 機能                   | 内容                                                     | 優先度 |
| ---------------------- | -------------------------------------------------------- | ------ |
| トップページ           | 事業紹介、理念、主要サービス、相談への導線               | 高     |
| 事業理念・サービス     | Think / Thankの理念、開発・保守サービス紹介              | 高     |
| 開発実績               | 掲載許可のある実績紹介（未掲載時は準備中表示）           | 高     |
| お問い合わせフォーム   | 名前、メール、会社名、相談内容、予算、希望納期を受け付け | 高     |
| AI事前相談ウィジェット | 画面右下の丸いボタンから開くポップアップチャット         | 高     |
| 会員登録 / ログイン    | 相談者・顧客向けのアカウント認証                         | 高     |
| 会員マイページ         | 自身の過去のAI相談履歴の確認、登録情報の確認             | 高     |
| プライバシーポリシー   | 問い合わせ・AI相談データの取り扱い・保存期間の明示       | 高     |

### 2.2 AI事前相談ウィジェット（右下丸ボタン＆ポップアップ）

- **UI配置**：エンドユーザー画面の右下に常時追従（`fixed`）する丸いアイコンボタンを配置する。
- **挙動**：ボタン押下でポップアップ（モーダルまたはドロワー）が開き、その中でチャット形式でやりとりできる。
- **役割**：相談内容の概要・予算感・希望納期などの整理をサポートする（正式な見積・契約確定は行わない）。
- **安全性・配慮**：
  - AIによる応答であり誤りを含む可能性があること、個人情報・機微情報・パスワードを入力しない旨を明記する。
  - APIキーはサーバー側で管理し、フロントエンドに露出させない。
  - AI利用不可時は通常のお問い合わせフォームへ誘導する。

### 2.3 AI会話履歴の保存（会員・ゲスト共通）

- **会員ユーザー**：ログイン中のユーザーID（`user_id`）に紐づけて会話セッションおよびメッセージをDBに保存する。会員はマイページから過去の会話履歴を閲覧できる。
- **未登録（ゲスト）ユーザー**：セッションIDまたは匿名トークン（`guest_token` / `session_id`）を用いて会話履歴をDBに記録し、後から管理画面で確認できるようにする。
- **会員登録時の紐づけ（推奨）**：ゲスト状態でAI相談した後に会員登録・ログインした場合、同一セッションの履歴を会員アカウントへ引き継げる設計とする。

### 2.4 エンドユーザー画面デザインシステム

- **コンセプト**：三色団子を思わせる春色、大きな角丸カード、広い余白、水彩風背景。
- **配色**：
  - コーラル `#E66B7C`（メインアクセント）、桜色 `#F8B5C5`、若草色 `#9FD6A3`、レモンイエロー `#FDFF26`
  - 背景 `#FFFFFF`、本文 `#363230`
- **書体・アイコン**：英字 `Cormorant Garamond` / 日本語 `Zen Kaku Gothic New` / アイコン `Lucide`
- **背景**：右上・左中央・右下の3エリアに水彩スポットを配置（既存デザインの色・位置・サイズを維持し、コンテンツ背面に配置）。
- **ロゴ**：桜色版（メイン）・若草色版（サブ）の添付画像をプロジェクト内に配置し、縦横比を維持して使用する。

## 3. 管理画面の要件

### 3.1 機能一覧

| 機能                 | 内容                                                           | 優先度 |
| -------------------- | -------------------------------------------------------------- | ------ |
| 管理者ログイン       | 管理者専用認証（一般会員とは完全分離）                         | 高     |
| ダッシュボード       | 売上・支出・利益・API監視状況の集計カード表示                  | 高     |
| 顧客管理             | 顧客・連絡先の登録、編集、検索                                 | 高     |
| 案件管理             | 顧客紐づけの案件、開発/保守区分、状態、金額、期日管理          | 高     |
| 問い合わせ管理       | 公開フォームからの相談内容の確認・ステータス管理               | 高     |
| **AI相談履歴管理**   | 会員・ゲスト双方のAIチャット履歴の一覧・詳細閲覧・検索         | 高     |
| 売上・入金・経費管理 | 請求・入金状況、経費・家事按分・証憑メモの記録                 | 高     |
| 会計CSV出力          | マネーフォワード確定申告向けの仕訳CSVエクスポート              | 中     |
| API死活監視          | 顧客システムAPIの毎日0時・12時自動チェック、ログ記録・異常通知 | 中     |

### 3.2 管理画面デザインシステム（Bootstrap 5）

- **フレームワーク**：Bootstrap 5（レスポンシブ対応）
- **レイアウト**：
  - **PC（992px以上）**：左側に固定サイドバーを常駐表示。
  - **スマホ（992px未満）**：左サイドバーを隠し、上部に固定トップバーを表示。**左上にハンバーガーメニューボタン**を配置し、タップでOffcanvasドロワーメニューを開く。
- **配色ルール（厳格）**：
  - **グラデーション完全禁止**（すべてソリッドカラー）。
  - **テーマ色**：若草色（`#47834C`）のみをプライマリ（ボタン・アクティブ状態・主要バッジ）に使用。
  - **マルチカラー例外**：ダッシュボードの集計カード並列表示（売上・支出・利益・監視）のみ役割別の色分けを許可。
  - **その他**：すべて無彩色（白・黒・グレー）で構成する。
