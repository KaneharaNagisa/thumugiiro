# エンドユーザー画面 要件定義書

## 1. 公開ページ・機能一覧

| 機能 | 内容 | 優先度 |
|---|---|---|
| トップページ | 事業紹介、理念、主要サービス、相談への導線 | 高 |
| 事業理念・サービス | Think / Thankの理念、開発・保守サービス紹介 | 高 |
| 開発実績 | 掲載許可のある実績を紹介する。掲載できる実績がない場合は準備中と表示する | 高 |
| お問い合わせフォーム | 名前、メール、会社名、相談内容、予算、希望納期を受け付ける | 高 |
| AI事前相談ウィジェット | 画面右下の丸いボタンから開くポップアップチャット | 高 |
| 会員登録 / ログイン | 相談者・顧客向けのアカウント認証 | 高 |
| 会員マイページ | 自身の過去のAI相談履歴と登録情報を確認できる | 高 |
| プライバシーポリシー | 問い合わせ・AI相談データの取り扱いと保存期間を明示する | 高 |

## 2. AI事前相談ウィジェット

### 2.1 表示・操作

- エンドユーザー画面の右下に、画面に追従する（`fixed`）丸いアイコンボタンを常時表示する。
- ボタンを押すとモーダルまたはドロワー形式のポップアップを開き、チャット形式でやりとりできる。

### 2.2 役割・制約

- 相談内容の概要、予算感、希望納期などの整理を支援する。
- 正式な見積・契約確定は行わない。
- AIによる応答には誤りが含まれる可能性があることを明記する。
- 個人情報・機微情報・パスワードを入力しないよう明記する。
- APIキーはサーバー側で管理し、フロントエンドに露出させない。
- AIを利用できない場合は、通常のお問い合わせフォームへ誘導する。

## 3. AI会話履歴の保存

- 会員の会話セッションおよびメッセージは、ログイン中のユーザーID（`user_id`）に紐づけてデータベースへ保存する。
- 会員はマイページから過去の会話履歴を閲覧できる。
- ゲストの会話履歴は、セッションIDまたは匿名トークン（`guest_token` / `session_id`）を用いてデータベースへ記録し、管理画面から確認できるようにする。
- **推奨**: ゲストが相談後に会員登録またはログインした場合、同一セッションの履歴を会員アカウントへ引き継げる設計とする。

## 4. エンドユーザー画面デザインシステム

### 4.1 コンセプト

- 三色団子を思わせる春色を基調とする。
- 大きな角丸カード、広い余白、水彩風背景を用いる。

### 4.2 色・書体・アイコン

| 用途 | 指定 |
|---|---|
| メインアクセント | コーラル `#E66B7C` |
| サブカラー | 桜色 `#F8B5C5`、若草色 `#9FD6A3` |
| アクセント | レモンイエロー `#FDFF26` |
| 背景 | `#FFFFFF` |
| 本文 | `#363230` |
| 英字書体 | Cormorant Garamond |
| 日本語書体 | Zen Kaku Gothic New |
| アイコン | Lucide |

### 4.3 背景・ロゴ

- 右上・左中央・右下の3エリアに水彩スポットを配置する。
- 水彩スポットは既存デザインの色・位置・サイズを維持し、コンテンツの背面に配置する。
- 添付画像の桜色版ロゴをメイン、若草色版ロゴをサブとしてプロジェクト内に配置する。
- ロゴは縦横比を維持して使用する。
