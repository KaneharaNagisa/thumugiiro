# 管理画面 要件定義書

## 1. 機能一覧

| 機能 | 内容 | 優先度 |
|---|---|---|
| 管理者ログイン | 一般会員とは完全に分離した管理者専用認証 | 高 |
| ダッシュボード | 売上・支出・利益・API監視状況を集計カードで表示 | 高 |
| 顧客管理 | 顧客・連絡先の登録、編集、検索 | 高 |
| 案件管理 | 顧客に紐づく案件の開発/保守区分、状態、金額、期日を管理 | 高 |
| 問い合わせ管理 | 公開フォームからの相談内容を確認し、ステータスを管理 | 高 |
| AI相談履歴管理 | 会員・ゲスト双方のAIチャット履歴を一覧・詳細閲覧・検索 | 高 |
| 売上・入金・経費管理 | 請求・入金状況、経費・家事按分・証憑メモを記録 | 高 |
| 会計CSV出力 | マネーフォワード クラウド確定申告向けの仕訳CSVをエクスポート | 中 |
| API死活監視 | 顧客システムAPIを毎日0時・12時に自動チェックし、ログ記録・異常通知 | 中 |

## 2. 管理画面デザインシステム

### 2.1 フレームワーク・レスポンシブレイアウト

- Bootstrap 5を使用し、レスポンシブ対応とする。
- **PC（992px以上）**: 左側に固定サイドバーを常時表示する。
- **スマートフォン（992px未満）**: 左サイドバーを隠し、上部に固定トップバーを表示する。
- スマートフォンのトップバー左上にハンバーガーメニューボタンを配置する。タップするとOffcanvasドロワーメニューを開く。

### 2.2 配色ルール

- グラデーションは全面的に禁止し、すべてソリッドカラーを使用する。
- テーマ色は若草色 `#47834C` のみとし、プライマリのボタン・アクティブ状態・主要バッジに使用する。
- ダッシュボードの集計カード（売上・支出・利益・監視）の並列表示に限り、役割別の色分けを許可する。
- 上記の例外を除き、白・黒・グレーの無彩色で構成する。
