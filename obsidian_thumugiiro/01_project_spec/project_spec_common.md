# プロジェクト確定仕様書

## プロジェクト概要

- アプリ名: THUMUGIIRO
- 目的: Think / Thankの理念に基づく事業紹介、相談受付、顧客・案件・会計情報などの管理を行う。

## 技術スタック・実行環境

- バックエンド: PHP 8.3 / Laravel 11
- 実行環境: Docker
- コンテナ構成: PHP-FPM / Nginx / MySQL 8.0 / Redis等

## システム全体の原則

- 公開側（エンドユーザー・会員）と管理側は、認証・権限・ルーティング・デザインシステムを完全に分離する。
- 青色申告の処理を自作システム内で完結させない。仕訳CSVを出力し、マネーフォワード クラウド確定申告等の会計ソフトへ取り込む。

## 絶対に崩してはいけない重要仕様

### エンドユーザー画面

- 詳細要件は [[enduser_requirements]] を参照。

### 管理画面

- 詳細要件は [[admin_requirements]] を参照。

## 禁止事項・運用上の注意

### システム全体共通

- `design_temp/` 内のソースは変更しない。

### エンドユーザー画面

- AI相談は相談内容の整理を支援するものであり、正式な見積・契約確定を行わない。
- AIのAPIキーをフロントエンドへ露出させない。

### 管理画面

- 管理画面はエンドユーザー側の認証・権限・ルーティング・デザインシステムと分離する。
- デザイン・レスポンシブ要件は [[admin_requirements]] を参照する。
